Como funciona

Cada venda desconta a quantidade do estoque. Cancelar uma venda devolve os itens ao estoque. Os registros ficam neste navegador; faça backup regularmente.

A venda não processa pagamentos: apenas registra o que foi vendido. Para receber pedidos pelo link de divulgação, informe seu WhatsApp nas configurações.

Divulgação

Crie um link de catálogo para compartilhar. A vitrine funciona sem cadastro dos clientes: eles selecionam o produto e enviam o pedido pelo WhatsApp. Para atualizar preços ou estoque, gere e compartilhe um novo link.

O link contém uma cópia dos produtos no próprio endereço. Catálogos grandes podem ultrapassar o limite de alguns aplicativos; nesse caso use os links individuais abaixo. Vendas recebidas pela vitrine devem ser registradas manualmente neste painel.
